# PyQt5 Calculator with History

A simple PyQt5 desktop application that allows users to perform mathematical operations (PGCD, PPCM, and Power) on two integers. The application provides a graphical user interface (GUI) to enter values, select operations, and view results. It also maintains a history of all calculations, saved in separate files for each type of operation.

## Features

- 📐 **PGCD (GCD)**: Calculates the greatest common divisor of two integers.
- 🔁 **PPCM (LCM)**: Calculates the least common multiple of two integers.
- ⚡ **Power**: Calculates A raised to the power of B.
- 💾 **History Saving**: All operations are stored in `.dat` files.
- 📊 **View Past Operations**: Load operation history into tables within the GUI.
- 📈 **Statistics**: Displays total number of operations and their percentages.

## Requirements

- Python 3.x
- PyQt5
